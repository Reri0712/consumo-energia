## Sobre o Projeto
Programa desenvolvido em Python para calcular o consumo elétrico mensal em kWh e estimar o custo financeiro com base no uso diário.

## Fórmula Utilizada
O consumo mensal é calculado por:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas/Dia} \times 30}{1000}$$
